## 每一刀，都连贯。

**拔刀，挥斩，归鞘。**<br>
刀身完全离鞘，再切入挥斩。收势后寻鞘、对齐、纳刀，自然衔接。刀鞘佩在腰侧，跟随身体移动。

**动作，从全身发起。**<br>
转髋带肩，屈肘运腕。双手、刀柄与刀鞘由同一套骨骼约束协调，原创动作编排参考居合的出入鞘方式，以及《鬼泣》的战斗节奏。

**熟悉的刀路，清楚的第一人称。**<br>
第一人称恢复拔刀剑原版 VMD 中刀与刀鞘的轨迹，保留快斩的原始节奏。打断连招时，刀与鞘共同完成短暂过渡。双手、手臂和袖子不再遮挡视野，待机刀柄保持可见。

两种视角共用动作时钟和刀身尺寸。第三人称使用完整人物骨骼，第一人称使用原版武器轨迹，因此刀路有所不同。镜头沿用重锋的行为：攻击时武器执行动作，不额外给世界视角叠加头部跟随旋转。

物品提示沿用重锋的字段顺序、颜色和显示条件，背包图标使用原有的旋转、缩放和耐久环。装有 RarityCore 时，拔刀剑物品不再叠加其额外稀有度标签和名称染色。

**熟悉的拔刀剑，继续向前。**<br>
地面与空中连招、SA、精准 SA、Super SA，以及刀剑、合成成长、魂系材料和幻影剑系统，在新版本中延续。内置英文与简体中文。

**按重锋的路线养刀。**<br>
基于[拔刀剑：重锋 1.9.65](https://github.com/0999312/SlashBlade_Resharped/tree/6e2a0a092fb794d7ea56fd83452869674f3ab1c7) 的实际代码，本版提供 **5 种基础刀、26 个命名刀定义（含断裂／封印变体）**，以及 **23 条工作台升级、1 条下界合金锻造、6 条耀魂材料配方和 6 条刀架配方**。JEI 可区分刀种，悬停前置刀即可查看养成门槛。

升级继承斩杀数、耀魂值、锻造次数与兼容的附魔，也保留自定义名称、持有者和刀的身份。旧版保存的基础刀可继续升级；旧材料箱、复制配方与活化／觉醒耀魂退出正常配方和物品列表，已有道具保留兼容。

**把重锋的玩法，带到现代 NeoForge。**<br>
内置的八类 SA 已接入各自的攻击逻辑。刀架支持剑技转移、特殊效果提取与安装，以及附魔耀魂强化。成长、掉落、自我修复、伤害和资源消耗按重锋规则实现，并提供服务端设置。旧具名刀会补齐一次对应 SA／SE，之后保留玩家的自定义更换。

### 选择你的剑技

| SA | 动作与效果 |
| :--- | :--- |
| 次元斩 | 锁定目标斩击，保留精准释放与 Super SA。 |
| 樱花终结 | 双向交叉连斩，包含地面与空中分支。 |
| 虚空斩 | 拔刀后的延迟爆发。 |
| 圆斩 | 环绕身体的连续斩击。 |
| 纵向驱动 | 向前飞行的纵斩剑气。 |
| 横向驱动 | 向前飞行的横斩剑气。 |
| 波刃 | 向前推进的多段剑气。 |
| 突刺 | 向前突进刺击，包含精准释放分支。 |

把刀放上刀架，手持**携带 SA 的耀魂宝珠**左键点击刀架，安装剑技。附魔小耀魂可在刀上存在同种满级附魔时复制其 SA。使用**携带 SE 的耀魂结晶**安装效果；空白结晶可提取允许复制和移除的效果。创造物品栏和 JEI 分别展示这些变体。

重锋内置的 SE **凋零之刃**需要 **20 级经验**：达到门槛后近战命中附加凋零，等级不足时持刀会让自己凋零。附魔耀魂还可在刀架上强化附魔，沿用重锋按材料档位计算的成功率，并消耗材料。

### 按你的世界调整

世界目录下的 `serverconfig/slashblade-server.toml` 提供 PvP、友好生物攻击、修复消耗、耀魂掉落、幻影剑消耗、锻造上限、锈刀生成与伤害倍率等设置。PvP 和友好生物攻击默认关闭，配置由服务端同步。

刀种和生物掉落使用可同步的数据包注册表。定义放在 `data/<命名空间>/slashblade/named_blades/<名称>.json` 与 `data/<命名空间>/slashblade/entity_drop/<名称>.json`。本版包含参考版本的 **26 个具名刀定义与 6 条生物掉落规则**；配方采用新版单数 `recipe` 目录。

**兼容范围：**本次移植重锋本体的内容与玩法系统。Forge 1.20.1 附属、EMI／Patchouli 联动及可选渲染桥接不能直接沿用；本版使用 JEI 与内置动画系统。暮色森林掉落需要适配当前版本的对应生物。跨版本 Forge 存档迁移尚未验证。

### 耀魂与锻造

断刀掉落小颗粒耀魂；4 粒合成 1 份耀魂碎片，2 份碎片加 1 铁锭合成耀魂铁锭。铁锭经熔炉烧炼成宝珠（200 tick），宝珠经高炉成为结晶（300 tick），结晶再经高炉成为偏方三八面魂（400 tick）。工作台转换保留同一种 I 级附魔；混合附魔或高等级附魔不能用于此转换。

铁砧每次锻造消耗 **1 个材料、1 级经验**，恢复耐久，并增加下表的耀魂值。每次锻造最多增加 1 点最大耐久，前 200 次有效；材料达到锻造上限后只能修复，不能继续刷耀魂值。

| 材料 | 锻造上限 | 每次增加耀魂值 |
| :--- | ---: | ---: |
| 破碎的耀魂 | 10 | 100 |
| 耀魂碎片 | 50 | 500 |
| 耀魂铁锭 | 100 | 1,000 |
| 耀魂宝珠 | 150 | 1,500 |
| 耀魂结晶 | 200 | 2,000 |
| 耀偏方三八面魂 | 2,147,483,647 | 5,000 |

击杀获得的耀魂值按经验掉落量与评分等级计算，每次最多 100。普通幻影剑消耗 2，剑阵消耗 20；普通 SA 优先消耗 20，不足时改为消耗 1 点耐久。Super SA 遵循下方列出的重锋规则。

| 运行环境 | 版本 |

## 挥出第一刀

| 动作 | 默认操作 |
| :--- | :--- |
| 攻击／衔接连招 | 鼠标左键 |
| 拔刀攻击 | 短按鼠标右键 |
| 剑技 SA | 按住鼠标右键蓄力，随后松开 |
| 精准 SA | 在精准窗口内松开，基础窗口为第 9–11 tick |
| Super SA | 在地面按住**疾跑键**一秒，自动释放 |

Super SA 与重锋一致：使用满足妖刀条件的附魔刀，击杀数至少 **1,000**、满耐久、未断刀且未封印。在地面持续按住疾跑键 **20 tick** 后自动释放，提前松开取消；同时潜行和移动时不会释放。基础消耗为最大耐久的一半，向下取整，耐久附魔、创造模式和不可破坏属性生效。释放刀对应的 Super 招式，默认招式施加两秒缓慢并生成范围次元斩。

## 构建之外，也经实机检验。

`port.30` 已通过 **139 项必需 GameTests**，覆盖成长路线、数据继承、耀魂经济、获取方式、刀架交易、SE、配置、注册表、八类 SA 的实际伤害，以及重锋超级 SA 的蓄力和耐久规则。客户端在含 RarityCore 的 **206 个模组**隔离实例中验证。提示检查覆盖显示条件和兼容性；图标检查将实际渲染边界与重锋的 OBJ 几何体及实际生效的 GUI 变换对照。

渲染检查对照第一人称几何体与原版 VMD 轨迹，包括突刺；检查打断、收刀衔接，以及左右持刀、转头和不同俯仰角。第三人称检查覆盖人物骨骼与实际实体渲染器，第一人称不提交手臂几何体。

战斗验证通过物品的服务端蓄力释放逻辑发动 SA，记录尸壳的实际生命值变化，录像期间不回血。上述检查覆盖内置内容；自定义模型比例、其他人物动画模组和长时间联机仍需另行测试。大幅挥斩时，刀身可能短暂离开画面。

## 从源码构建

安装 **JDK 25**，使用仓库自带的 Gradle wrapper。首次构建会下载依赖。

```sh
git clone https://github.com/Viking602/SlashBlade-Re.git
cd SlashBlade-Re
```

**Windows（PowerShell）**

```powershell
.\gradlew.bat build
```

**macOS / Linux**

```sh
sh ./gradlew build
```

产物：`build/libs/SlashBlade-26.1.2-0.1.2-26.1.2-port.30.jar`。

在临时检出目录中，使用相同 wrapper 执行 `runGameTestServer` 可运行服务端回归测试。该任务会写入同级的 `test-gametest` 目录。
